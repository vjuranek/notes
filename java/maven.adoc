= Maven

== Config

* `export JAVA_TOOL_OPTIONS="-Djavax.net.ssl.trustStore=/etc/pki/ca-trust/extracted/java/cacerts"` - force java/maven to use system CA trust

== Mirrors

In `settings.xml`

```
  <mirrors>
    <mirror>
      <mirrorOf>central</mirrorOf>
      <id>central-internal</id>
      <name>central-internal</name>
      <url>MAVEN_CENTRAL_MIRROR</url>
    </mirror>
  </mirrors>
```
